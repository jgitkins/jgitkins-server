### Planned Features (Roadmap)

#### 파일 트리 조회
repositories/{ownerType}/hrk11mmmm/repod2/{branch}/{tree}
저장소 상세화면 접근시, 파일목록이 트리형태로 노출되고, 파일(blob)이 아닌, 디렉토리(트리) 클릭시 파일트리 화면으로 이동하면서 
사용자가 선택한 디렉토리의 하위 파일 및 디렉토리를 읽을 수 있는 기능을 제공한다.

브랜치를 선택한 경우에도 URL변경과 함께 이동한다.

#### 파일 상세 조회
repositories/{ownerType}/hrk11mmmm/repod2/{branch}/{blob}
저장소 상세화면 접근시, 파일목록이 트리형태로 노출되고, 디렉토리(트리)가 아닌, 파일 클릭시 파일 상세 화면으로 이동하고, 
파일을 wysiwyg 편집기로 읽을 수 있는 기능을 제공한다.
